asimov-pyomicron Documentation
==============================

Welcome to the documentation for **asimov-pyomicron**, an interface between the asimov workflow management system and the pyomicron event trigger generator package.

This plugin enables Asimov to submit and manage `omicron-process` jobs for gravitational wave event trigger generation on HTCondor clusters.
